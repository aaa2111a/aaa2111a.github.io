Minimum average holdAverage real hold per recent collection — the core anti-flipper filter. Always on.
Required

We look at the last few collections the wallet minted from. For each one we measure how long it held that collection — from its first mint until it sold out, or until now if it still holds it — then average across collections. Each collection counts once, so dumping a pile of one mint can't game it.

min avg days
over last N (max 5)

Example: the last 5 collections it minted were held ~46 days on average — clears a 30-day bar. A serial flipper averages a day or two and fails.

Anti-farming filters
Paid mints onlyCount only NFTs the wallet actually paid for. Kills free-mint farming.
ETH min / mint

A bot can mint from 5 free collections in one script for ~$0. With this on, those don't count — only mints where ETH actually left the wallet. Set a minimum to ignore cheap/dust mints too (0 = any paid mint counts). Applies to mints, distinct collections, average hold and diamond hands. With paid-only on, average hold and diamond hands need at least 2 paid collections.
